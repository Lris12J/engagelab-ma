  • 开始组件：事件"注册 / 订阅成功"触发（一次性事件，不可再次进入；SDK 自带埋点，零开发）
  • 等待 1 小时：先观察用户是否自主浏览
  • 等待事件 24 小时：监听"页面浏览"（SDK 自带）→ 已浏览 / 超时未浏览分流
  • 已浏览 · Email：用户活跃中 → 直接发按用途选型指南（工程材料 / 大尺寸 / 入门）+ 会员券
  • 超时未浏览 · 可发送时间 09:00–21:00 + Email：会员券到账提醒 + 选型入口
  • 等待 48 小时 → 可发送时间 + Email：机型对比 + 评测集
  • 提前退出：事件"完成购买"→ 自动退出旅程
  • 转化统计：监听"完成购买"事件，统计时间 3 天
预期效益参考
欢迎序列转化参考 8–12%（优秀水平 12–18%），首封打开率 45–60%——约为常规营销邮件的 2–3 倍。 欢迎内容绑定会员分层定价（"入会即享会员价"比一次性折扣码更能沉淀长期关系）， 每一个留下的邮箱都是 Amazon 渠道拿不到的自有用户资产。

场景 3｜大促预热三段式（黑五 / 网一）

Q4 主战场 大促节奏 属性圈选 · 老客/新客分流 · 预热 → 开卖 → 倒计时

大促前 7 天上线：老客收耗材配件专享预告、新客收整机大促预告；开卖日发开卖通知，3 天未购的在收官前收最后 24 小时提醒。

建议渠道：Email · Web Push　｜　触发方式：属性「邮箱不为空」（旅程于大促前 7 天发布），30 天后可重入　｜　退出条件：完成下单即自动退出

旅程编排示意图
业务痛点
大促依赖开卖日自然流量，缺预热蓄水——高客单硬件决策周期数周，来不及被说服的买家直接流向平台比价； 老客与新客收到同一套群发内容，会员专享价触达不到位。
旅程组件配置

  • 条件分支：按属性"累计购买次数"分流（已购机老客 / 未购机新客）
  • 老客路径：可发送时间 09:00–21:00 + Email 耗材配件专享预告
  • 新客路径：可发送时间 + Email 整机大促预告
  • 等待 7 天（至开卖日）→ 可发送时间 + Email：开卖通知 + 限时价
  • 等待事件 3 天：监听"完成购买"→ 已下单退出 / 超时继续
  • 可发送时间 + Web Push：最后 24 小时提醒
  • 提前退出：事件"完成购买"→ 自动退出旅程
  • 转化统计：监听"完成购买"事件，统计时间 5 天
  • 埋点：购买事件与场景 1 同批接入
预期效益参考
高客单买家决策数周，开卖日才触达等于放弃了大部分预算——预热蓄水决定大促成绩。 本品类买家强锚定"史低价"，预热主打史低与早鸟锁价；场景 8 的心愿单人群是天然蓄水池。今年建好，明年复用。

场景 4｜首打激活引导与评价

降工单 · 保口碑 购后激活 打印机绑定事件触发 · 4h/24h/48h 递进 · App Push + Email

打印机绑定后 4 小时推装机连网、切片软件设置与首打测试件教程；24 小时未开打推视频教程 + 网络排障，再 48 小时未打转客服邮件介入（内含工单入口）。首打成功的恭喜、邀入社区，3 天后请求评价。

旅程编排示意图
业务痛点
网络配置、切片软件、材料适配问题集中在首打阶段，全靠人工客服逐单解答； 首打失败直接转化为退货与差评——而评测与评分正是这个品类的转化命脉。
旅程组件配置
  • 开始组件：事件"打印机绑定成功"触发（每台仅一次首绑，不可再次进入）
  • 等待 4 小时 → App Push：开箱装机、连网与切片软件设置 + 首打测试件教程（刚绑定，用户在活跃窗口）

  • 可发送时间 + Email：客服协助介入（内含工单入口链接）

  • 转化统计：监听"首次打印成功"事件，统计时间 7 天

5数据安全与合规

数据安全
  • 全链路 TLS 加密传输，传输层与存储层数据分离
  • VPC 网络隔离，数据中心多活灾备，可按客户安全需求灵活扩展
  • 海外用户数据存储于海外数据中心，可按目标市场合规要求选择数据区域，支持签署数据处理协议（DPA）
  • PII 字段脱敏、基于角色的访问控制（RBAC），SDK 接入不改变现有账号与推送链路
合规支持
  • 已通过 GDPR 合规认证 + SOC 2 Type II 安全审计——覆盖欧美市场核心合规要求
  • 可协助满足各目标市场本地数据保护法规要求（美国 CCPA / CAN-SPAM 等）
  • 支持用户数据删除、导出、退订与同意管理等合规权利；Email 退订与 Push 权限状态自动同步
  • 消息发送记录保留 60 天，可随时导出用于合规审查
运营护栏

· 频控策略：旅程级频控，限制每用户每日 / 每周 / 每小时的消息数量上限，多旅程自动去重；

· 可发送时间：基于终端用户本地时区自动控制发送窗口，多市场并行不出现深夜打扰；

· 内容预览：消息发送前支持完整样式预览；

· 提前退出：用户完成目标行为（如下单）立即从旅程退出。
