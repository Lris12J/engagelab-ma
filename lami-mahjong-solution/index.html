一、客户现状与市场机会

久游网（2003 年成立于上海，中国第一代互联网游戏运营商）自主研发的休闲游戏已出口至东南亚、印度、台湾、香港等全球 40+ 国家和地区。 棋牌休闲（Board / Card）是全球留存表现最强的手游品类之一——玩法熟悉、习惯性回访、金币经济与社交牌桌形成稳定的长期留存曲线。 对久游而言，用户资产已经沉淀，缺的不是买量，而是把「注册→首局→首充→回访→迁移」各环节用自动化旅程接起来，让存量池持续产生增量。

旅程编排示意图
业务痛点
大量新注册玩家没有完成第一局对局就流失——棋牌游戏「完成首局」是形成金币经济与社交牌桌黏性的起点。 当前缺乏激活引导，首局完成与首日回访全靠自然转化。注册后前 24 小时是干预的最佳窗口。

  • 提前退出：事件「完成首局」→ 自动退出（进入首充旅程）
  • 转化统计：事件「完成首局」，监听 1 天
  • 等待事件：30 分钟内先观察是否自行完成首局——已完成则引导领礼，未完成再触达
  • App Push：一键匹配 + 新手教学局 Deep Link
  • 等待事件：6 小时内等待完成首局；超时 → 可发送时间 → WhatsApp
  • App Push（领礼）：完成首局后引导领新手礼包 + 首日签到
  • 可发送时间：终端时区 9:00–22:00（第 2 轮 WhatsApp 前加入）
  • 再次进入：不可再次进入（注册事件仅发生一次）

同类棋牌休闲游戏通过激活旅程，首局完成率预期提升 8–15%，并为 D1 留存提供上游供给。

场景 2｜沉默玩家分层唤醒（3 / 7 / 14 日）客户重点

留存 / 召回 再次进入：3 天后
旅程编排示意图
业务痛点（对应客户诉求：用户进来几天后沉默、不知如何营销）
玩家沉默几天却没有任何唤醒动作，是当前最大的存量流失口。棋牌类长期留存本应很强， 「一刀切群发」既打扰活跃用户又召不回沉默用户。正确做法是按沉默天数分层、 用「牌友/牌桌在线 + 递进回归礼」精准触达，越早触达单位召回成本越低。
旅程组件配置
  • 开始组件：属性「最后登录时间距今超过 3 天」
  • 提前退出：事件「登录」→ 自动退出
  • 转化统计：事件「登录」，监听 5 天
  • 条件分支：按最后登录距今天数分流（3–6 天 / 7–13 天 / ≥14 天）
  • 可发送时间：各路径消息前均加入，终端时区 9:00–22:00
  • 触达策略：轻度沉默用金币翻倍 + 牌友在线 Push；中度叠加 WhatsApp 专属回归礼 + 新赛季；深度流失加 SMS 大额回归礼兜底
  • 再次进入：3 天后（与进入条件阈值对齐）
可参考指标
分层召回旅程可将沉睡玩家回登率提升 20–40%；轻度沉默窗口的单位召回成本显著低于深度流失。

场景 3｜首充激活 · 新手超值礼包（3 日黄金期）

首次付费转化 再次进入：不可再次进入
一句话版本

完成首局且从未付费 → 立即推送新手超值礼包；24 小时未付费 → 按登录天数分层（≥2 天 WhatsApp 限时超值礼、<2 天 Push 引导）；48 小时仍未付费 → SMS 提醒活动到期。

建议渠道：App Push · WhatsApp · SMS　｜　触发方式：事件「完成首局」+ 属性「累计付费金额 = 0」　｜　退出条件：付费成功即自动退出

旅程编排示意图
业务痛点
棋牌休闲玩家中仅少数会完成首次内购，而高价值玩家（约 1–2%）贡献 50–70% 收入。 完成首局后的 72 小时是首充黄金窗口——此时玩家刚理解金币经济，需在最恰当的时刻给出 超值礼包（如新手礼包 / Coin Jar / 超值卡）的清晰价值主张。
旅程组件配置
  • 开始组件：事件「完成首局」+ 属性：累计付费金额 = 0
  • 提前退出：事件「付费成功」→ 自动退出
  • 转化统计：事件「付费成功」，监听 1 天
  • 收入统计：事件「付费成功」，金额属性 purchase_amount，监听 1 天
  • 第一步：完成首局即时推送新手超值礼包（玩家仍在活跃窗口，无需可发送时间）
  • 等待事件：24 小时内等待付费；超时 → 可发送时间 → 条件分支
  • 条件分支：按累计登录天数分层（≥2 天走 WhatsApp 限时超值礼，<2 天继续 Push 首充引导）
  • 等待事件：48 小时内等待付费；超时 → SMS 提醒活动即将到期
  • 再次进入：不可再次进入
可参考指标
首充激活旅程可将 7 日首充转化率提升 2–4%；触发类 Push 点击率显著高于全量群发。

场景 4｜老款 → 新款 App 迁移客户重点

用户迁移 再次进入：7 天后 EUID 跨 App + Webhook 千人千面
旅程编排示意图
业务痛点（对应客户诉求：老款不再迭代，要迁移到新款 App）
老款《Lami Mahjong》沉淀了 50 万+ 用户，新款《Lami Mahjong Pro》需要承接这批存量。 若无系统化引导，老款用户很难自发下载新款、更担心「金币 / VIP / 等级资产」丢失。 关键是跨两个 App 识别「老款活跃、新款未注册」人群，并让迁移礼包体现「你的资产可继承」。
旅程组件配置
  • 开始组件：属性「老款 App 活跃」且「新款 App 未注册」（EUID 统一视图跨 App 识别）
  • 提前退出：事件「新款 App 注册 / 登录」→ 自动退出
  • 转化统计：事件「新款 App 注册 / 登录」，监听 3 天
  • Webhook：调用久游自有接口，取回该玩家老款资产 / VIP 等级，供后续文案千人千面
  • 条件分支：按老款价值分层（高价值付费/VIP vs 普通）
  • 可发送时间：各路径消息前加入，终端时区 10:00–22:00
  • 高价值路径：WhatsApp 专属迁移礼（继承金币 + VIP）+ 新款商店 Deep Link
  • 普通路径：App Push（老款内）迁移公告 + 新款迁移礼包
  • 等待事件：3 天内等待新款注册；超时 → Email 迁移指引 + 资产对照
  • 再次进入：7 天后
可参考指标
基于「身份打通 + 资产继承 + 分层触达」的迁移旅程，迁移注册转化预期提升 15–30%， 高价值老款用户的迁移优先级最高、单位价值最大。

场景 5｜锦标赛 / 赛季冲刺提醒

Live Ops 再次进入：7 天后
一句话版本

结算前 2 天仍未达标的玩家 → 按排名临界度分流（接近晋级线冲刺文案 / 距离较远参与补强）Push 提醒；1 天未参赛 → WhatsApp 最后机会。

建议渠道：App Push · WhatsApp　｜　触发方式：属性「结算日 T-2 + 本期未达标」，7 天后可重入　｜　退出条件：达成目标或领奖即退出

旅程编排示意图
业务痛点
每周金币锦标赛、每月赛季排行榜是拉米麻将的核心活跃与变现引擎，但大量玩家因忘记进度错过结算， 导致参与度与活动内付费双双受损。在结算前按排名临界度精准催促，可显著提升冲榜参与与相关付费。
旅程组件配置
  • 开始组件：属性「赛季 / 锦标赛结算日提前 2 天」+「本期参赛未达标」
  • 提前退出：事件「奖励领取完成」或「达成目标排名」
  • 转化统计：事件「参与锦标赛对局」，监听 3 天
  • 可发送时间：终端时区 10:00–22:00（棋牌晚高峰可适当后延）
  • 条件分支：按排名临界度分流（接近晋级线 → 冲刺文案 / 距离较远 → 参与补强文案）
  • 等待事件：1 天内等待参与对局；超时 → WhatsApp 最后机会提醒
  • 再次进入：7 天后（匹配赛季 / 锦标赛周期）
可参考指标
结算前进度提醒，可将锦标赛 / 赛季参与率提升 12–25%，并带动活动窗口内付费。

场景 6｜连续签到保持（日活抓手）

活跃习惯 再次进入：1 天后

旅程编排示意图
业务痛点
新款内置 7 日签到与连续奖励机制，是最低成本的日活抓手。但玩家一旦某天忘记登录、连签中断， 养成的回访习惯就会断裂。在连签即将中断的傍晚时段轻量提醒，可用极低成本维系日活与习惯回路。
旅程组件配置
  • 开始组件：属性「连续签到天数 ≥ 3」且「今日未签到」
  • 提前退出：事件「今日签到完成」→ 自动退出
  • 转化统计：事件「今日签到完成」，监听 1 天
  • 可发送时间：终端时区 18:00–22:00（签到与晚间牌局高峰）
  • App Push：AI Write · 「你的 N 天连签即将中断，今日签到领金币」
  • 等待事件：当日 6 小时内等待签到完成；超时结束（不追加，避免打扰）
  • 再次进入：1 天后（每日可触发）
可参考指标
连签保持提醒是低成本高频抓手，签到率与次日回访预期提升 15–25%，直接支撑 DAU 稳定性。

六、合规与安全

数据安全
  • 全链路 TLS 传输加密
  • VPC 网络隔离，存储层与传输层分离
  • PII 字段脱敏存储与访问
  • 基于角色的权限控制（RBAC）
认证与合规
  • 已通过 GDPR 与 SOC 2 认证
  • 可协助客户满足各目标市场本地数据保护法规要求
  • 数据中心可按客户安全需求灵活扩展
运营护栏
  • 频控策略：旅程级限制每日/每周消息数量
  • 勿扰时段：可发送时间组件控制本地时段
  • 内容预览：发送前支持样式预览
  • 消息记录：发送记录保留 60 天
  • 提前退出：完成目标行为后自动停止触达
