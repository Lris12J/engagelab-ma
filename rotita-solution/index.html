1业务现状：高频走量的快时尚，增量在「即时触达」这一层

跨境 DTC 快时尚女装以全品类、高频上新、每日 Flash Sale 与清仓驱动走量， 独立站承接绝大部分流量、App 承载高粘性复购人群。这种模型下，用户决策窗口极短—— 加购、浏览、心愿单收藏后的几十分钟到几小时是转化黄金期， 而邮件擅长内容沉淀却不擅长「分钟级」抢回。增量往往不在「要不要做 MA」， 而在把 App Push / Web Push / SMS 的即时触达补进已有生命周期这一层。

EngageLab MA 在同一平台原生覆盖 App Push / Web Push / Email / SMS / WhatsApp， 通过事件与 API 对接品牌现有的独立站、App 与自研业务系统， 以编排层叠加而非替换的方式，先跑通可量化的即时触达增量，再决定整合节奏。

4核心旅程详细编排

以下为面向跨境 DTC 快时尚女装的推荐编排：按场景选用最合适通道，全部使用 EngageLab MA 真实旅程组件（开始 / 等待事件 / 条件分支 / 可发送时间 / 消息组件 / 结束）。

旅程 1（P0）：弃单多通道即时挽回

加购未支付 → 即时挽回：高客单（≥1.5×AOV）按市场走 SMS / WhatsApp、其余 Email，2 小时监听支付。

建议渠道：App Push · SMS · WhatsApp · Email　｜　触发方式：事件「加入购物车」，1 天后可重入　｜　退出条件：支付成功即自动退出

业务痛点与通道逻辑

时尚品类弃单率约 78-85%，成熟品牌纯邮件恢复常见 8-12%，瓶颈是「打开与响应不够快」。App Push 抓加购后黄金窗口，高客单按市场用 SMS（美/英/澳）或 WhatsApp（南欧/拉美），Email 承载尺码指南与评价详述。

旅程组件配置

进入条件：事件: 加入购物车

提前退出：事件: 订单支付成功

转化统计：事件: 支付成功，监听 2 小时

再次进入：允许，间隔 1 天

条件分支：客单价 ≥ 1.5×AOV → 再按市场分 SMS / WhatsApp；其余 → Email

预期效益（测试目标）

相对成熟邮件基线弃单恢复率再 +3~5%（如 10% → 13-15%）

建议与现有弃单邮件做 50/50 并行对照

旅程 2（P0）：浏览未加购召回（独立站 Web Push 主力）

浏览详情超 60 秒未加购 → 已装 App 走 App Push、未装走 Email（独立站以 Web Push 为主力）。

建议渠道：Web Push · App Push · Email　｜　触发方式：事件「浏览详情页超 60 秒」，3 天后可重入　｜　退出条件：加入购物车或支付即自动退出

业务痛点与通道逻辑

独立站承接大量高意向浏览却未加购，付费 Retargeting CTR 常低于 1%。Web Push 免装 App 即可即时召回网页流量；已装 App 用户走 App Push 二次触达；Email 沉淀搭配与 UGC 内容。

旅程 3（P0）：新客欢迎 + 首购激励

新用户注册 → 欢迎 + 首购激励序列，1 天监听首单转化。

建议渠道：App Push · Email　｜　触发方式：事件「用户注册」　｜　退出条件：首次下单即自动退出

业务痛点与通道逻辑

新客首单转化决定获客 ROI。欢迎与品牌故事最适合 Email（内容完整、可沉淀）；新客专属优惠（如首单立减）用 App Push 提高打开与行动；未转化再用 Email 尺码指南与热销榜收口。

业务痛点与通道逻辑

快时尚每日 Flash Sale 与清仓走量，用户收藏 / 加入心愿单后常观望价格。以收藏行为触发即时提醒：App Push 抓活跃用户，Web Push 覆盖网页端；仍未转化再用 Email 强调「库存告急 / 限时特价」制造紧迫感。

订单发货后 → 按首单品类（服饰 / 配饰）分流跨品类连带推荐，14 天监听复购。

快时尚单客 SKU 广度大（连衣裙 / 上衣 / 泳装 / 配饰）。发货状态用 App Push 即时告知；搭配 / 保养指南用 Email 承载长内容；再按首单品类做跨品类关联推荐（App Push 轻提醒 + Email 详述），提高连带与复购。

业务痛点与通道逻辑

快时尚联系人基数巨大但活跃率低，一刀切折扣群发既贵又伤品牌。按 60/90/180 天分层：浅沉默用 App Push 轻触达新品，中深沉默用 Email 讲权益礼包；末触达按市场选 SMS（美/英/澳）或 WhatsApp（南欧/拉美）。配合 MEP 计费，只对当月进入旅程用户计费。
